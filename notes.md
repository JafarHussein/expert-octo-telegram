# Environment configuration

1. Lets create a virtual environment that seperates our project dependencies
    python -m venv venv - This command creates a virtual environment 

2. Lets activate our virtual enviroment using the following command

    cd venv
    Scripts/activate.bat- This is the command that activates our virtual environment

3. Lets install fastapi

    We going to install fastapi using the following command 

    pip install "fastapi[standard]"- This installs the backend framework we are going to work with
